Connect to GitHub

Publishing saves the painting to the gallery’s GitHub repository. It needs an access token, which stays on this device only.

How to get a token
  1. Open GitHub → New fine-grained token and sign in.
  2. Name it (e.g. “Gallery uploads”) and choose an expiration.
  3. Under Repository access, pick Only select repositories and choose the gallery’s repository.
  4. Under Permissions → Repository permissions, set Contents to Read and write.
  5. Click Generate token, copy it, and paste it below.
